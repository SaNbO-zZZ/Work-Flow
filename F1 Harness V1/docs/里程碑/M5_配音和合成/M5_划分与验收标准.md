# M5 配音和合成：划分与验收标准

**状态：进行中**（2026-10-09 开工，划分已获用户确认）。做法沿用 M3、M4：子 Agent 分任务执行，总控逐项复核。

## 目标
从 G1 定稿的逐字稿出发，自动走完下面几步：
- **配音**：剪映 AI 配音。
- **配音后处理**：查读错、压缩停顿、生成零标点字幕。
- **配素材与粗剪**：G2 审核时可以试听配音、看粗剪。
- **合成与混音**：分层合成画面和声音，混音参数沿用雪邦。
- **硬检查**：自动检查成片有没有硬失败。
- **交付**：成片、零标点 SRT、标题和简介、横竖版封面、制作记录。

## 开工前的实测基准
- **雪邦前瞻成片**（含水印版）：1920×1080，30 帧，H.264；AAC 48 kHz 立体声；时长 179 秒。
- **雪邦成片的声音**：整体响度 −16.7 LUFS，响度范围 2.8 LU，峰值 −2.2 dBFS。旧项目的交付清单写的目标是 −16 LUFS、真峰值 −1.5 dBTP。
- **混音参数**按《品牌与混音》：
  - 人声 0 dB，人声 EQ 在 1581 Hz 降 2.5 dB（Q 0.5）。
  - BGM −20.5 dB。
  - 口播时 BGM 最多再压 3.5 dB（阈值 −26 dBFS，起效 20 ms，恢复 400 ms）。
  - BGM 整片循环，接缝处 0.1 秒交叉淡化；片尾不淡出。
- **旧项目的做法**：
  - 剪映配音是用户手动操作的。雪邦那期用户在三个音色里选了"热血解说员"。
  - 1.3 倍是在剪映里设置后导出的，只做过试听，最后交付用的是原速。
  - 读错检查用 mlx-whisper 量化模型，旧项目里已经下载好，903 MB。
- **本机条件**：
  - 剪映专业版 11.5.0 已安装。
  - ffmpeg 有变速（atempo）、避让、EQ、响度归一等滤镜，没有 rubberband。
  - Hermes 环境里还没装语音识别。

## 验收标准
| 标准 | 怎么验 |
|---|---|
| ① 用户选定 1.3 倍版本 | 同一段稿子出两版：剪映里 1.3 倍导出，以及原速导出后由程序加速。不标明哪版是哪版，让用户试听后选定，选定的做法写进设置，以后每期照用 |
| ② 混音实测与雪邦参数一致 | 对试做成片分轨实测：<br>人声电平和 EQ；BGM 基准在 −20.5 dB ±1 dB；避让最多 3.5 dB<br>整体响度和雪邦成片（−16.7 LUFS）相差不超过 1 LU；峰值不超过 −1 dB<br>BGM 是指定文件，循环接缝 0.1 秒，片尾不淡出 |
| ③ 试做成片通过全部硬检查 | 试做一期成片，M5-7 的全部硬检查通过；留给 M6 的文本类检查项，这次由总控人工核对，写进验收报告 |

## 可行性验证结果（M5-1，2026-10-10）
- 剪映草稿 `draft_content.json` 是加密的，程序写不了草稿。改为：菜单“文件→新建草稿”→ 字幕 → 新建字幕 → 手动写字幕（智能文案窗口）→ 粘贴全文 → 配音选择 → 热血解说员 → 添加到轨道。已写成 `hermes/jianying.py` 的 `generate()`，雪邦全文 1103 字生成 66 段约 67 秒，每步截图。
- 配音文件在草稿的 `textReading/` 下，顺序是乱的；用语音识别按原稿排序，66 段连续无缺漏，整体相似度 0.876（低匹配 6 段都是数字句，识别出阿拉伯数字）。
- 剪映内 1.3 倍：时间线全选后在“变速”里设倍数，片段起点不变，会留空隙，需要程序再压停顿；音色卡片上的语速设置脚本点不开。
- 验收① 两版样本已出（同一套停顿压缩和响度，只差变速方式），放在 `验收1_试听/`，等用户盲听选定。
- **验收① 结果（2026-10-10）**：用户选样本 2 ="程序加速"（原速导出后 ffmpeg atempo 1.3），理由是声音更洪亮清楚。已写进设置 `voice.speed_method=程序加速`、`voice.speed=1.3`，以后每期照用。剪映只负责原速配音，不再在剪映里变速。

## 文件与接口约定（总控定，子 Agent 照做）
每期目录 `productions/<期号>/` 下：
- `02_文案/逐字稿.md`：G1 定稿（带 `[F#]` 等标记）。
- `03_配音/`
  - `配音稿.txt`：narration 输出，直接粘进剪映的文本。`配音稿.json`：`{"units": [{"say", "show", "para"}], "warnings": [...]}`。单元在每个 。！？，、 后切，剪映每段音频正好是连续若干单元；say 是朗读文本（可能有读音替换），show 是字幕文本。
  - `raw/`：剪映原始分句（乱序，扩展名 .wav 实为 mp3）。
  - `配音.wav`：voice_post 输出，48 kHz 单声道，已排序、去头尾静音、1.3 倍、句间停顿上限 0.5 秒（对齐样本 2 实测，见复核记录）、剪映句中切开处 0.1 秒；不做响度归一（合成时统一做）。
  - `对齐.json`：`{"speed", "gap", "duration", "segments": [{"i", "file", "text", "start", "end", "match", "asr"}], "issues": [{"kind": "读错|停顿|语速", "segment", "at", "detail"}]}`。`text` 是该句配音稿原文（带标点），`start/end` 是在 `配音.wav` 里的秒数。
  - `字幕.json`：subtitles 输出 `[{"start", "end", "text"}]`，零标点。`试听.mp3`：G2 试听用。
- `06_合成/`
  - `时间线.json`：edit 输出，见下。`粗剪.mp4`：960×540 低清预览（含配音、字幕、水印）。
  - `成片.mp4`：compose 输出，1920×1080、30 帧、H.264、AAC 48 kHz 立体声。
- `07_QA/硬检查.json`：`{"passed": bool, "items": [{"name", "ok", "hard", "detail"}]}`。
- `08_交付/`：成片、零标点 SRT、标题和简介、横竖版封面、制作记录。

`时间线.json`：
```json
{"fps": 30, "size": [1920, 1080], "duration": 168.4,
 "voice": "03_配音/配音.wav", "subtitles": "03_配音/字幕.json",
 "video": [{"asset_id": 4, "shot_idx": 3, "src_in": 12.3, "src_out": 15.1, "start": 0.0, "end": 2.8,
            "crop": null, "segment": 0, "reason": "…"}],
 "overlays": [{"path": "05_图形/xxx.png", "start": 10.0, "end": 14.0}],
 "credits": [{"text": "画面：xxx", "start": 0.0, "end": 2.8}]}
```
`video` 首尾相接铺满全片；`crop` 为 `{"x","y","w","h"}`（源画面像素），裁台标用；素材原声一律静音。
