# F1 Hermes V1 文档目录

所有计划、提示词、工程说明、里程碑验收都以 Markdown 存在这里，是唯一正本。
给接手的 AI 编码工具的总入口是 `/Volumes/HermesCore/CLAUDE.md`（交接文件，每一步后更新）。聊天里定下的内容，当场存进来。

| 目录 | 放什么 | 更新规则 |
|---|---|---|
| `计划书/` | 实施计划书（B1–B9 定稿） | 计划有改动时，先把旧版加日期另存，再改 |
| `提示词/` | `common/`（公共规范、品牌与混音）、`branches/`（前瞻、资讯、复盘、科普）、`历史版本/`、`变更记录.md` | 程序直接读取这里；改之前先备份到 `历史版本/<时间>/`，改完记入变更记录 |
| `里程碑/` | `00_里程碑总表.md`（划分、验收标准、状态）和每个里程碑的子文件夹（验收报告） | 每个里程碑验收时写报告，并更新总表状态 |
| `工程/` | 工程说明：文件位置、代码模块、常用命令、关键实测结论 | 每个里程碑结束时更新 |
| `案例分析/` | 参考案例逐字稿、分析脚本 | 新案例分析后追加 |
