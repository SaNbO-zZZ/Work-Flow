## 7. 踩过的坑（不要再踩）
- **VS Code 编辑工具和终端混改同一文件会写乱**：对编辑器已打开的文件用 sed/cat 改了磁盘后，再用编辑工具改，会基于旧缓冲区写回，导致内容错乱或回退（`工程说明.md`、`M2_验收报告.md`、`server.py` 都中过招）。同一文件只用一种方式改；改完用终端 `grep`/`sed -n` 核对磁盘实际内容。
- exFAT：不能放 APFS 映像（挂不上，所以用 HFS+）；SQLite 不放 exFAT；会生成 `._*` 影子文件，写完要 `find ... -name '._*' -delete`。
- httpx 默认读系统代理：访问本机一律 `trust_env=False`；外网请求可能经代理卡死，外层再包 `asyncio.timeout()`。
- 后台进程访问外置卷要"完全磁盘访问权限"，必须由 .app（Mach-O 启动器）拉起；启动器 fork 出服务后自己退出，否则再次双击不打开网页。
- 同一个 Python 类里属性名不能和模块名相同（`jobs: jobs.Jobs = None` 会把模块遮住）。
- Codex exec 开联网搜索用 `-c web_search="live"`；每次调用有约 1.6–2 万 token 的固定开销（加载技能时约 3.5 万）。
- FastF1 主数据源失败会降级到不完整的备用源；赛历刷新已拒绝站数骤减的数据。
- frankfurter 汇率接口要自定义 User-Agent。
- Motorsport.com 对脚本请求返回 403，但链接是真的（浏览器 UA 可打开）。
