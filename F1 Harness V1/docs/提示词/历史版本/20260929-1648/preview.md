# 前瞻分支 v0.2（重建版，待用户复核）

所有步骤同时遵守 `common/公共规范.md`；§8 以 `common/品牌与混音.md` 为准。

## §1 定位
- 本周大奖赛开赛前的前瞻。风格以 F1视界为主体，补充 F1围场内外式的数据和历史。

## §2 输入
- FastF1 赛历与历史数据、FIA 文件、天气（Open-Meteo）、新闻来源（抓取脚本接口 / GPT 抓取）、用户给的链接。

## §3 时长
- 目标 210 秒，范围 195–225 秒。

## §4 结构
1. 钩子（前 5 秒）。
2. 4–7 秒处求赞。
3. 赛程（换算北京时间），赛程之后求关注。
4. 正文：赛道特点、天气、车队/车手看点、数据与历史。
5. **必须有"本赛道名场面"段。**
6. 结尾：评论区提问。

### 参考案例原话（从案例逐字稿找回，照这个节奏写，不要逐字照抄）
| 位置 | F1视界 A（西班牙新赛道） | F1视界 B（阿塞拜疆） |
|---|---|---|
| 0–4 秒 | “终于等到这条全新的赛道登场 欢迎来到西班牙大奖赛比赛周” | “欢迎来到阿塞拜疆比赛周 你是否还记得去年6次红旗的变态排位赛” |
| 4–8 秒求赞 | “先点个赞 让我们来聊聊这条赛道究竟会精彩万分还是无聊至极” | “所以先点个赞 让我们来聊聊今年的巴库还会发生什么” |
| 赛程 | “先来快速过一下时间” | “首先要注意的是比赛时间” |
| 赛程后（约 17–19 秒） | “欢迎你关注我的频道” | “欢迎你关注我的频道” |
| 结尾 | “所以你认为谁能够拿下这条赛道的首个冠军呢 欢迎你在评论区里告诉我 也希望可以得到你的点赞收藏和关注支持 我们下个视频见” | 以赞助竞猜环节收尾（“嘉实多极护竞猜时刻”），即广告位用法示例 |
- F1围场内外（C、D）开场：“车迷朋友们 欢迎回来 本周末F1终于要重返……”，不求赞，直接进正题。
- 总控人格参数（原记录为"0.1–0.5"）：含义未能找回，待用户确认后补写。

## §5 文案
- 前 50 秒语速不能拖（雪邦前 50 秒的教训：碎句加标点导致每句停顿）。
- 天气、赛程等信息类内容要配叠层（见 §6）。

## §6 画面与素材（按语境匹配）
| 口播内容 | 优先素材 |
|---|---|
| 赛道整体环境、地理位置 | F1 赛道宣传片，或含该赛道的城市宣传片；没有再用官方赛道图、CG 模拟圈、城市航拍 |
| 车队、车手 | 车队官方运营视频 |
| 明确提到名场面、赛道情况、故事 | **必须用比赛实况** |
- 天气预报、赛程等：素材照放，上层叠天气预报截图或原创图解。

## §7 声音
- 素材原声静音；车手言论口播转述（授权例外见公共规范）。

## §8 品牌与混音
- 见 `common/品牌与混音.md`。

## §9 QA
- 公共硬失败全部适用；另查：缺"本赛道名场面"段、时长明显超出 195–225 秒（扣分）。

## §10 交付
- 成片、零标点字幕、封面（统一模板）、标题和简介、制作记录。

## §11 禁区
- 用肯定语气说传闻；人身攻击；编造数据。
