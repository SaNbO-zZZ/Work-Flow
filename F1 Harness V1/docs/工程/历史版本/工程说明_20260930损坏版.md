## 代码模块
| 文件 | 作用 |
|---|---|
| `config.py` | 路径、Codex CLI 位置、屏蔽的全局技能、并发与重试参数、角色默认模型、推理强度中文名 |
| `db.py` | 建表与迁移（只能在列表末尾追加）、连接、事务 |
| `codex_runner.py` | 调用 Codex（模型、推理强度、工作目录、沙箱、联网、续接对话）、解析 JSONL 事件、识别额度用完、记录 token、读订阅额度、读可选模型 |
| `pipeline.py` | 状态流转、四道关卡、打回去向、每个阶段的步骤批次 |
| `episodes.py` | 新会话、立项（期号、目录）、暂停/继续/取消/插队、关卡通过/打回 |
| `scheduler.py` | 调度：先来先做可插队、最多 3 期（待审不占名额）、剪映单占、重试 3 次、额度用完只等待、重启恢复 |
| `prompts.py` | 按五层组装提示词并计算版本号 |
| `appserver.py` | 常驻的 Codex app-server 客户端：开/续对话、每轮指定模型和推理强度、逐字输出、token 与额度推送 |
| `chat.py` | 总控对话：存消息（含该消息用的模型）、解析动作块（立项/暂停/继续/插队/取消）、记 token、汇总用量和折算金额 |
| `pricing.py` | API 公开价（官网抄录）和美元兑人民币汇率（每天一次） |
| 启动：双击桌面 F1 Harness.app（会自动挂载映像、拉起服务、打开 http://127.0.0.1:8790）
# 手动挂载映像（一般不需要（网页实时推送）和系统通知 |
| `server.py` | 网页服务：只监听 127.0.0.1:8790，Host/来源/自定义头校验，内容安全策略 |
| `calendar.py` | 赛历：FastF1 拉赛程（北京时间）、每天比对变动、时期判断（比赛周/发车区/夏休/冬歇）、比赛日、按分支起期名里的大奖赛名 |
| `glossary.py` | 译名表：内置词典建议 + GPT 补缺，用户审核；给赛历、期名、G1 标黄用 |
| `fia.py` | FIA 官网 F1 文件：解析最新两站、发现新文件、频率表 |
| `facts.py` | 事实表：`[F#]` 数字 / `[S#]` 说法，渲染给提示词、去标记、逐句核对数字 |
| `weather.py` | Open-Meteo 天气（预报 / 历史），写成 `[F#]` 事实；各赛道坐标 |
| `news.py` | 新闻来源：用户脚本接口（预留，设置项 `news.script_url`）→ 不可用时 GPT 联网抓；总控挑前三 |
| `jobs.py` | 定时任务：赛历每天 06:00、FIA 按频率表、新闻每天 08:00；网页可"立即执行" |

## 关键实测结论
- APFS 映像放在 exFAT 上无法挂载，所以改用 HFS+。
- Codex CLI：`/Applications/Codex.app/Contents/Resources/codex-cli/bin/codex`（0.158.0-alpha.2.1）。
- token 来自 `exec --json` 的 `turn.completed.usage`；额度来自 `codex app-server` 的 `account/rateLimits/read`；可选模型来自 `~/.codex/models_cache.json`。
- 屏蔽全局技能用调用参数 `-c skills.config=[{path=...,enabled=false}]`，不改文件。
- 技能脚本默认写 `~/.hermes`，已通过环境变量改到映像和每期文件夹。
