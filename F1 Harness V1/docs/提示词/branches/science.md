# 科普分支 v0.1 骨架（重建版，待用户复核）

所有步骤同时遵守 `common/公共规范.md`；§8 以 `common/品牌与混音.md` 为准。

## §1 定位
- 讲清楚一个 F1 知识点，不追时效。也包括"规则前瞻"，比如 2027 年规则变动讲解。
- 参考案例：F1视界"小科普"（尾流战术、box box 词源、BOA 救援）。

## §2 选题
- 用户指定优先；Hermes 可从最近新闻里找切入点提议，需用户批准。
- 选题要挂上最近发生的事，至少一句。

## §3 时长
- 统一 170–210 秒，目标 190 秒。不分子类型。

## §4 结构
1. 钩子（≤5 秒）+ 主题花字。
2. 挂最近的事。
3. 正文：按内容选一种写法——条件→代价→收益→案例；逐个词条讲来历；旧做法→问题→新做法按步骤讲。
4. 升华一句。
5. 结尾：评论区提问 → 点赞关注 → "我们下次见" → 预告下一期。

## §5 文案
- 系列编号只用于内部、发布标题和封面，**口播和画面文字里绝不出现"第 N 期""欢迎来到我的频道"**。
- 规则只能引用 FIA 已正式公布的文件，标 `[S#]` 并写条款号；未公布的只能说"据报道"并附来源。
- 历史案例必须核对年份和分站。

## §6 画面与素材
- 可以用知识卡片、遥测曲线加标注框、赛道分段图、历史影像、简洁示意图（concept-diagrams），也可以用非 F1 素材帮助解释（比如讲词源用赛马画面）。
- 演示类素材右上角标来源。数据段允许长镜头。

## §7 声音
- 同公共规范。

## §8 品牌与混音
- 见 `common/品牌与混音.md`。

## §9 QA
- 公共硬失败全部适用；另加：没有来源的说法、历史案例年份或分站错误、口播或画面文字出现系列编号。

## §10 交付
- 成片、零标点字幕、封面（统一模板，可含系列编号）、标题和简介、制作记录。

## §11 禁区
- 把未公布的规则说成定论；编造历史数据。
