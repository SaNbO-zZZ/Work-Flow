## 照 Hermes Agent 桌面版的地方
- 配色：浅色文字 #17171a、主色 #0053fd、底色 #f8faff；深色跟随系统；侧栏毛玻璃；小圆角；细线。
- 聊天为主页；设置用浮层（Esc 关闭）；卡片无边框、操作按钮在卡片下方；审批用卡片堆叠；输入框上方可折叠的状态栏。
- 按钮不用原生悬停提示。

## 可以点的地方
- 左侧会话和"素材库 / 用量 / 经验笔记"切换页面；"设置"打开浮层（模型分工表）。
- 输入框打 `/` 出现命令列表；模型和推理强度下拉（低、中、高、极高、最高、神临），改了之后提示变蓝，点发送回到 gpt-6-astra · 高。
- 状态栏标题点一下折叠。
- G2 卡片右上"在独立窗口打开"弹出 G3 终审窗口。
- 文案卡里 F3、F7 鼠标停上去显示来源；黄底是待审译名。
