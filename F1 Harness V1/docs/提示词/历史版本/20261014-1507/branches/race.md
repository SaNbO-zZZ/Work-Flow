# 赛事复盘分支 v0.3（重建版，待用户复核）

所有步骤同时遵守 `common/公共规范.md`；§8 以 `common/品牌与混音.md` 为准。

## §1 定位
- 练习、冲刺、排位、正赛的复盘，自媒体吐槽风，以车队和车手为主。

## §2 输入
- FastF1 场次数据（成绩、圈速、轮胎、天气、赛事指令）、FIA 文件（处罚、干事决定）、新闻来源、用户给的链接。
- 实况素材优先级：抓取脚本（接口预留）> 用户给的链接 > GPT 自己找。

## §3 期型与时长（期型由用户指定）
| 期型 | 目标 | 范围 |
|---|---|---|
| P（单节练习） | 130 秒 | 115–150 |
| P12（一练+二练） | 200 秒 | 180–225 |
| Q（排位） | 170 秒 | 150–195 |
| P3Q（三练+排位） | 220 秒 | 195–250 |
| S（冲刺） | 155 秒 | 135–175 |
| SQ+S（冲刺排位+冲刺） | 190 秒 | 170–215 |
| R（正赛） | 250 秒 | 210–300 |
- 冲刺排位和冲刺连着做就并入 S 类期型，分开做就不并。

## §4 结构
- 上一节的问题要在下一节跟进，比如二练跟进一练的问题：放在前半段，篇幅不宜长。
- 结尾固定顺序：评论区提问 → 点赞关注 → "我们下次见" → 预告下一集。
- 参考案例结尾原话（从逐字稿找回）：
  - 正赛 R1/R2/R3（F1视界）：“欢迎你在评论区留下你的看法 点赞关注推荐 我们下个视频见”
  - 冲刺 S1/S2：“也别忘了点赞推荐和关注我的频道”

## §5 文案
- 每个数字标 `[F#]`，来源 FastF1/FIA。
- 积分榜按口播内容灵活放车手榜或车队榜。

## §6 画面与素材
- 排名塔只在关键节点出现，3–5 秒，放在右侧或水印下方。
- 讲到具体事件可以用比赛实况，但发车、超车、缠斗、事故、红旗这类关键回合合计不超过全片 10%，每段连续不超过 5 秒，不要连成集锦；其余用数据图、积分榜、车载、人物和车队画面（2026-10-12 抖音禁播后定）。

## §7 声音
- TR：默认只用文字卡加口播转述；经用户本期授权可以用原音（此时口播让位、BGM 再压、配中文字幕卡）。

## §8 品牌与混音
- 见 `common/品牌与混音.md`。

## §9 QA
- 公共硬失败全部适用；另查：G3 前重新拉官方成绩和处罚，与文案不一致即硬失败。

## §10 交付与时限
- 正赛：赛后 24 小时内出片；其他期型没有硬时限。
- 成片、零标点字幕、封面（统一模板）、标题和简介、制作记录；广告位 `[AD]` 按公共规范处理。

## §11 禁区
- 编造数据或处罚；人身攻击。
