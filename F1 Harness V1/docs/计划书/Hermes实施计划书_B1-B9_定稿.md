## 阶段 A 结论（摘要）
- 分支：资讯、前瞻、赛事复盘、科普（V1 骨架）。
- Benchmark 权重：事实准确 26 / 剪辑与节奏 20 / 开头吸引力 17 / 画面贴合度 15 / 文案可听性 14 / 规格合规（品牌+混音+时长）8。
- 3 条历史成片（阿塞拜疆正赛、雪邦前瞻、巴库围场简报）用户评 60 分，作为棘轮起点；科普用第一期分数作起点。
- 用户指出的毛病：雪邦 1:14 素材复用且不到 1 秒闪切；天气预报类口播应在素材上叠截图或原创图解；巴库 1:10"催单｜客服"配音在词组中间怪停顿；雪邦前 50 秒语速拖沓（实测 347 字/分，之后 384，原因是碎句加标点，每句停顿 0.4–0.8 秒）。
- 科普：统一 170–210 秒；有系列编号但口播和画面文字不提，可上发布标题和封面；含"规则前瞻"。
- 口播文本口语化、少标点；字幕零标点；最短镜头 1.2 秒但以成片流畅为准。

## B1 总体架构、存储、运行方式
- **启动**：和 F1 中台一样。桌面 `F1 Harness.app`（C 语言启动器，完全磁盘访问权限），开机自启，本机 `127.0.0.1:8790`，只能在这台 MacBook 上访问，单实例。图标：法拉利 F1 车队盾形车标（仅本机自用）。
- **存储**：全部在移动硬盘 `F1 Hermes V1/`。代码、Python 环境、数据库、技能放在硬盘上的磁盘映像里（M1 实测后改为 HFS+ 格式）；素材、配音、成片直接放硬盘 `productions/`。
- **技术**：Python 3.12（uv）+ FastAPI + Jinja2 + HTMX，零 npm；SQLite；ffmpeg；FastF1；调用 Codex App 自带的 CLI。
- **合成**：剪辑合成用 ffmpeg；剪映只做"激昂解说"AI 配音。
- **Codex**：用 Codex App 自带 CLI（0.158），支持 gpt-6-sol、gpt-6-astra 等。
- **排队**：按用户发起先后，网页有手动插队按钮；同时最多 3 期；剪映同时 1 期。
- **界面**：照 Nous Research 的 Hermes Agent 桌面版。
- **Google Drive**：用 rclone，审批通过后全量上传（用户 Drive 5T）；目录"日期/视频类型/期名/"；逐个文件核对后本地保留 7 天自动删除，删前一天网页提醒并可"再留 7 天"。
- **素材卡**：每个素材在本地建卡（来源、标签、缩略图、Drive 位置、使用记录、画面指纹），永久保留，用于反查 Drive 旧素材。
- **素材使用**：同一段画面整期只出现一次（同一原片不同片段可分开用）；取用顺序：本期新素材 → Drive 里从没用过的 → 其他期用过的（必须用户在审核页点"同意"）。

## B2 数据模型和状态机
- 一个会话 = 一期；闲聊会话不排队。
- 9 张表：期、消息、任务、关卡、事实表、素材卡、素材使用、用量、归档。
- 流程：排队 → 选题与资料 → **G0 选题确认** → 写逐字稿 → **G1 逐字稿** → 配音 → 配素材与粗剪 → **G2 配音与粗剪** → 合成与QA → **G3 成片** → 上传 Drive → 归档倒计时 → 本地已清理。
- 等用户审核的期不占并发名额；失败自动重试 3 次再找用户。
- 文件夹命名：`日期-分支-大奖赛名-当天序号`，如 `20260929-复盘-巴林大奖赛-01`；复盘、前瞻一律用所讲那一站；资讯、科普按日期：比赛周写本站，夏休写"夏休"，冬歇写"冬歇"，赛季中两站之间的空周写"发车区"。
  - 时期判断（2026-09-30 用户确认）：按周一到周日算周，含正赛（当地日期）的那周是比赛周；夏休按官方口径——官方文章称匈牙利站之后、荷兰站之前为夏休，FIA 2026 Section F 第 F3.1.1a 条规定车队须在 7–8 月内停工连续 14 天，程序据此取"与 7–8 月重叠至少 13 天且重叠最多"的那段两站间空档（2026 为 7-27 至 8-16）；其余两站间空周为发车区；最后一站之后到下赛季第一站比赛周之前为冬歇。
- 子目录：01_资料 02_文案 03_配音 04_素材 05_图形 06_合成 07_QA 08_交付 logs。

## B3 Codex 调度
| 模型与推理强度 | 角色 |
|---|---|
| gpt-6.1-sol 高 | 总控、梗核实、图形 |
| gpt-6-astra 高 | 文案、剪辑决策、QA 评审（另开对话独立评审） |
| gpt-6.1-sol 中 | 找素材、新闻抓取、资料、素材打标、配音操作 |
- 2026-10-11 用户按《全局模型分工与 Token 优化表》改定上表。
- 聊天框默认跟总控一致（gpt-6.1-sol 高）；自动流水线按上表。
- 聊天框切换模型和推理强度（2026-09-29 M2 验收时用户修改）：
  - **闲聊会话（还没立项）**：手动选的模型会一直保留，直到用户自己再改；换会话、刷新页面都不会变。
  - **立项后的项目会话**：立项时自动回到聊天框默认模型；之后在项目会话里换模型，**只对这一条消息触发的动作有效**，发完回到默认模型。
- 推理强度中文名：低、中、高、极高、最高（max）、神临（ultra）。
- 不做额度保护；额度用完时任务自动等待恢复，不算失败次数。
- 提示词五层：公共规范 → 分支提示词（含 §8 品牌与混音）→ 步骤指令 → 本期上下文 → 经验笔记。每个任务记录提示词版本；提示词修改须用户批准并保留历史版本。
- 经验笔记：每期 G3 后总结教训，用户批准后写入。
- 顶部显示：订阅剩余额度 | 本对话 token 与折算金额（美元+人民币，按 API 公开价折算，不编造价格）| 今日累计；另有用量页（一天 24 小时曲线和明细表）。

## B5 数据层
- 新闻/视频抓取脚本：只留接口，等用户做好再接；脚本不可用时由 GPT 直接抓全部内容。GPT 每天 08:00 抓一次，比赛日不额外抓，素材资料不足时才临时抓。
- FastF1：赛历（北京时间，每天刷新，变动时通知）、场次数据；2018 年前只有成绩。
- 事实表：数字 `[F#]`（FastF1/FIA），非数字说法 `[S#]`（附链接摘录）；QA 检查数字对应和数值一致；复盘 G3 前重拉官方成绩和处罚。
- FIA 文件检查频率：比赛日每小时；比赛周其他日子每 2 小时；发车区每天；夏休、冬歇每天。
- 天气：Open-Meteo 免费接口。
- 译名表：车手、车队、大奖赛、赛道；FastF1 拉原名 → Hermes 建议 → 用户审核；待审译名在 G1 标黄一起审。

## B6 素材和图形
- 素材来源优先级：脚本抓取（未接）→ 用户链接（yt-dlp）→ GPT 网上找 → Drive 未用过的 → 跨期复用（须同意）。
- B 站：在 Hermes 设置页扫码登录，登录状态只存本机；不收账号密码。
- 打标：镜头切换点抽关键帧拼图，GPT 打车队/车手/赛道/场景/镜头类型标签，标记自带字幕和其他频道台标。
- 带其他频道台标的素材：能不用就不用，非用不可裁掉台标。
- 画面指纹查重：同一期同一段画面出现两次即硬失败；跨期碰到用过的弹复用卡。
- 剪辑时间线程序检查：重复画面、A-B-A-B、未授权原声为硬失败；镜头短于 1.2 秒和自带字幕只提醒。
- 叠层：网页截图（Swift 小工具）+ 黄色马克笔；FastF1 数据图；排名塔 3–5 秒；零标点字幕；花字标题卡；右下角出处小字。
- 字体：思源黑体（是否加粗看成片再定）。
- 技能（M1 已装）：whisper、clip、grounded-citations、humanizer、rss-feeds、reddit-reading、blocked-page-recovery、concept-diagrams；已有 agent-caption、ffmpeg-skill、playwright 直接用；hyperframes、manim 不装。

## B7 配音与合成
- 配音前整理文本：去标记、只在句号逗号处切、圈速/车号/年份/单位转口语读法、英文名换审过的译名、易错读音表。
- computer use 操作剪映（新建草稿 → 粘贴 → 激昂解说 → 1.3 倍 → 导出），操作前发系统通知，用户可点"稍后"推迟。
- 1.3 倍速两种做法（剪映内加速导出 / 原速文件由程序加速）M5 各出一版给用户试听再定。
- 后处理：whisper 查读错；词组中间停顿超过 0.15 秒标出；句间停顿压到 0.3 秒；分段语速检查；按对齐生成零标点字幕（每行约 16 字）。
- "避让"里的人声 = 我方 AI 口播（及授权的 TR 原声）。
- 合成图层（下→上）：素材（原声静音）→ 信息叠层/数据图 → 排名塔 → 字幕 → 出处小字 → 水印。
- 混音沿用雪邦参数（见《品牌与混音》）；输出 1920×1080、30 帧、H.264；响度以雪邦成片实测为准。
- 封面：从成片挑帧（程序初筛 + clip + GPT 选最贴合调性的一帧）+ **一套统一封面模板**（先设计、用户批准，每期都用）；生成后 GPT 检查可读性和贴合度。
- 标题和简介：不进 G3，成片最终渲染开始后直接发给用户。
- 交付：成片、零标点 SRT、标题和简介、封面（横版、竖版）、制作记录。

## B8 QA 与 Benchmark
- 三层：程序硬检查 → 独立 AI 评审 → 用户 G3。
- 硬失败：缺水印或位置尺寸不对；BGM 非指定文件；BGM 超过 −18 dB；未经授权人声；同一段画面两次；A-B-A-B；跨期复用未同意；数字无 `[F#]` 或数值不符；复盘官方成绩处罚复核不一致；字幕有标点；未审译名；科普出现"第 N 期"；标题肯定语气说传闻；分辨率帧率不对；峰值超过 −1 dB。
- 只提醒：镜头短于 1.2 秒、自带字幕、语速偏慢、词组中间停顿；时长超范围扣分。
- 评分标准写明 60/80/100 分样子，60 分以 3 条历史成片为样本；M6 校准 3 条落在 60±5。
- 用户在 G3 打分校准 AI；连续相差超过 10 分重新校准。
- 棘轮：低于分支基线自动返工 2 轮再交用户；基线 = max(原基线, 最近 5 期中位数)。
