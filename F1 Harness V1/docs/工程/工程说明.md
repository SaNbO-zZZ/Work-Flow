## 关键实测结论
- APFS 映像放在 exFAT 上无法挂载，所以改用 HFS+。exFAT 上还会生成 `._*` 影子文件，需要定期删除。
- Codex CLI：`/Applications/Codex.app/Contents/Resources/codex-cli/bin/codex`（0.158.0-alpha.2.1）。
- token 来自 `exec --json` 的 `turn.completed.usage`；额度来自 `codex app-server` 的 `account/rateLimits/read`；可选模型来自 `~/.codex/models_cache.json`。
- 屏蔽全局技能用调用参数 `-c skills.config=[{path=...,enabled=false}]`，不改文件。
- 技能脚本默认写 `~/.hermes`，已通过环境变量改到映像和每期文件夹。
- Codex exec 开联网搜索：`-c web_search="live"`（没有 `--search` 参数）。
- 汇率 frankfurter 需要自定义 User-Agent，否则 403；备用 open.er-api。
- FastF1 主数据源失败会降级到不完整的备用源，赛历刷新时已拒绝"站数骤减"的数据。
- 外网请求经系统代理可能卡死，httpx 超时不一定生效，外层要再包 `asyncio.timeout()`；访问本机的 httpx 一律 `trust_env=False`。
